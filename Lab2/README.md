# Killercoda scenario: Django course assessment final project

This folder is a Killercoda scenario built from the supplied IBM Markdown instructions.

## Files
- `index.json`: Killercoda scenario configuration.
- `intro.md`: original introduction and objectives.
- `step*/text.md`: original instructions divided into Killercoda steps.
- `finish.md`: original summary.

## Publish
1. Push this folder to a GitHub repository connected to your Killercoda Creator profile.
2. Add the repository and branch in Killercoda Creator Repository.
3. Configure the read-only deploy key and webhook as described in the official creator guide:
   https://killercoda.com/creators/get-started

## Notes on preserving the source
The learner-facing wording, task requirements, code samples, solution sections, assessment requirements, and image URLs have been retained. Only the source file's IBM-specific page/file/application directives were converted into Killercoda-compatible Markdown organization:
- `::page` became scenario intro/step/finish boundaries.
- `::openFile` became a visible file-path reference.
- `::startApplication` became a Killercoda traffic link for the same port and route.

No verification scripts or automatic setup commands were added, because the source instructions do not define automated checks or an alternative setup sequence.
